# ⚡ Energy & Utilities

Agents in this industry affect essential household services, so a correct program name is
not enough. The evaluation must prove that the service path remained usable before the
deadline, that evidence was minimized, and that the agent did not invent authority.

| Verified lab | Question | Specialty |
|---|---|---|
| [Household Energy Lifeline](household-energy-lifeline/) | Can an agent preserve a household's available energy-service path without approving assistance or promising a hold? | `public-value` `service-continuity` `accessibility` `human-in-loop` |

All accounts, programs, policies, households, balances, and medical-review flags are
fictional. For real assistance, use official state, tribal, territorial, utility, or local
program channels.
