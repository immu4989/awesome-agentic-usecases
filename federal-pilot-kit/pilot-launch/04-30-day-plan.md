# 04 — Evidence-first 30-day plan

| Window | Work | Exit evidence—required before the next window |
|---|---|---|
| Days 1–5: Bound | Confirm problem, baseline, affected groups, authority, data, environment, stop line, and stakeholder access. | Approved brief; role map; data/security/privacy intake; frozen initial requirements; dated baseline. |
| Days 6–10: Design | Write exact acceptance cases, clean twins, transfer traps, accessibility checks, cost scenarios, monitoring, and incident drills. | Versioned test manifest; independent owner; holdout plan; expected outcomes/reasons/authority; evidence map. |
| Days 11–15: Integrate | Configure the narrow workflow; connect only approved tools/data; collect responder evidence and limitations; rehearse rollback. | Traceable build/configuration; access list; evidence response; rollback receipt; unresolved dependency list. |
| Days 16–20: Test | Run deterministic and adversarial cases; independently reproduce critical claims; measure task quality, safety, latency, cost, and operator burden. | Raw receipts; exact gap ledger; incident results; reproducibility notes; no hidden critical miss in an average. |
| Days 21–25: Operate bounded | Conduct time-boxed shadow or advisory use with human review; collect user/operator feedback; monitor drift and accessibility. | Daily monitoring receipts; interventions; false-positive/negative examples; feedback themes; updated risk register. |
| Days 26–28: Exit rehearsal | Export agency-owned data/configuration, remove access, restore prior workflow, and verify deletion/retention commitments. | Portability and rollback receipts; inventory reconciliation; residual access list; continuity result. |
| Days 29–30: Decide | Compare evidence with the original gates; document changes, gaps, incidents, costs, rights impacts, and lessons. | Signed human continue/revise/stop/extend decision with conditions, owners, dates, and next review. |

Scope changes require a dated change record: requester, reason, affected requirements/tests/data,
new risks, approving official, and whether earlier evidence remains valid. Never silently weaken a
threshold because the pilot is near Day 30.
