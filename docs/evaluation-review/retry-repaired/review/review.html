Methods and interpretation limits

Descriptive enumeration of supplied recorded outcomes, not a release gate, future-run probability, confidence interval, or evidence of production safety. All criteria are tested jointly on the same repeat; any-pass is a contrast, not permission to retry a consequential action. Threshold validity, preregistration, execution authenticity, independence, scoring correctness, and population representativeness are not verified. No repeats or scenarios are dropped. Repeat indices are not timestamps and this is not a consecutive-run analysis. Unlisted metrics are not reviewed. Source hashes bind supplied JSON values, not trusted provenance.
